Vehicle Distribution Analysis Dashboard

A dynamic data visualization project built using Tableau to analyze global vehicle distribution trends, market shares, and regional densities. 

💡 Key Insights & Features
1. Cleaning up the layout with containers
Instead of floating things around randomly and hoping they look good, I used layout containers to build a structured grid. I stacked the header and main sections vertically, then used horizontal containers to place related charts side-by-side. This keeps everything perfectly aligned, clean, and balanced, no matter what size screen you are viewing it on.Adding a dynamic

2. Top X filter
I wanted to give users the control to choose exactly how much data they want to look at. I built a parameter that lets you adjust the ranking depth on the fly. When you change the slider, a custom calculation filters the charts instantly. I also tied this input to the chart titles, so if you select ten items, the title updates to say Top 10 automatically

3.Choosing the right mix of chartsTo keep the dashboard interesting and insightful, I avoided using the same types of charts over and over. I mixed things up by using geographic maps to spot regional trends, timeline graphs to track changes over the years, and sorted bar charts to make comparing different categories quick and intuitive.

4.Setting up interactive filters
I wanted the dashboard to feel like a cohesive, exploratory tool rather than a collection of separate charts. I set up dashboard actions so that clicking on a specific region or bar in one chart automatically filters the rest of the page. Combining this with universal dropdown filters lets you slice and dice the data seamlessly with zero lag.
